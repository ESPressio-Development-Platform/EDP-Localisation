# Tutorial Platform Localisation Bundle

This is a deliberately minimal **tutorial-only** Platform Localisation Source Bundle used by the EDP-Localisation getting-started guide.

It exists so a developer can run the complete authoring/compiler workflow from an EDP-Localisation checkout without first obtaining another repository.

It is **not** the production ESPressio Platform localisation bundle and must not be treated as such in a real product. Production applications should pin the released Platform Localisation Source Bundle selected by their ESPressio platform baseline.
